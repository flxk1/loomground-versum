# Security policy

## Supported versions

Versum is currently alpha software. Security fixes are made on the latest release line only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for this repository. Include the affected version or commit, reproduction steps,
impact, and any suggested mitigation. Please avoid accessing data that is not yours and allow
the maintainers time to investigate before public disclosure.

Versum processes untrusted documents locally. Until a report is resolved, isolate suspicious
input, avoid running Versum with elevated privileges, and retain the source file and command
output needed to reproduce the problem.
